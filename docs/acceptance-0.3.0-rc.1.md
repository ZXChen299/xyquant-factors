## 线上实测内容

正常证书校验下 TCP 约 328ms、TLS 握手约 406ms；TLS 1.3。请求较新协议 `2026-07-28` 后服务协商为 `2025-11-25`，无会话头，符合当前无状态配置。原始类型或额外字段错误返回 HTTP 200 的 MCP 工具错误 `invalid_request`，不回显输入；这不是成功数据响应。

旧功能覆盖策略目录两页、说明、原表表现、净值两页、团队、因子搜索／说明和单因子单日单股票的一行预览。研究结果固定版本，保留来源文件名、大小及 SHA-256；表现和净值返回统计口径，实际表现样本保留 null。分页不重复，不将有界净值视为完整回测。

新增统一搜索验证所有已授权类型、两页固定快照及空结果；策略对比验证同一发布版本的两个策略、请求顺序、原始字段、统计期间、来源和 null；发布更新验证软件版本与研究发布事件、资料时间与净值截止日分别呈现。未创建新研究发布事件或计算新绩效。已安装插件的一次搜索分页调用耗时约 28.5 秒并成功，另一次策略搜索约 14.7 秒；尚未区分网络、重试和服务处理耗时，本轮不是负载或响应时间验收。

每轮真实客户端的三个 NOT_RUN：有界净值样本不含 null，不能证明线上净值空值案例；只有一个已发布事件，无法实测第二页历史；没有修改真实账户或进行全量导出。这些不是失败，合成空值和游标边界测试另有覆盖。
