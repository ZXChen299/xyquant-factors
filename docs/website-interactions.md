# 研究网页交互

本次更新服务端网页资源；Windows 插件保持 `0.3.0-rc.1` 未签名预发布版本，无须重装或新增 OAuth 授权。

## 详情与导航

从策略目录或统一搜索打开策略说明，会显示桌面侧栏或手机半屏面板；手机可展开阅读长内容。关闭、Esc 或浏览器后退会返回原列表位置，前进可重新打开。因子工作台的说明也支持同样面板。原详情链接仍可直接打开或刷新；修饰键点击保留浏览器的新标签行为。私有内容每次由现有认证接口重新读取。

## 净值图

手机长按可以查看原始日期和值，再沿水平方向查看相邻点；普通竖向滑动仍用于页面滚动。图表提供相邻点、时间范围和全屏按钮，也支持键盘左右键。区间操作只改变图表可见范围，不重新计算收益、表现表或排序。原始空值显示“无数据”并保留断线，不补点或插值。

## 浏览位置

登录后按账号保存搜索词、分类、分页快照及滚动位置，最多保留 7 天。再次打开会重新验证身份、请求当前允许读取的资料，旧版本失效时要求刷新。不同账号使用不同分区；退出登录会清除当前账号的偏好并通知同浏览器其他标签页。浏览器禁止存储时退回当前页面内存。

不持久化研究响应、净值、联系方式、密码、token、CSRF、下载文件或导出请求。草稿预览不保存浏览偏好。浏览器安全设置完全禁止访问存储时，页面不能保证清除原先已被浏览器隔离的存储；恢复访问后可使用浏览器网站数据设置清除。

## 手机操作与下载

手机底部提供当前页面的快捷按钮，避免长页面来回查找。按钮复用已有操作、防重复点击和“停止等待”；停止本地等待不会取消已提交的后台导出。

因子导出按服务器状态显示排队、生成和可下载，结果未确认时先核对原请求编号；显式重试保持原编号和条件。研究文件显示请求、接收、大小与 SHA-256 校验，校验通过才交给浏览器下载。没有可靠字节总量时只显示阶段，不显示估算百分比。

“已交给浏览器”不代表已写入设备磁盘，请在浏览器下载记录确认保存结果。原生因子下载链接无法从页面核验浏览器保存完成，不会声称已完成校验。失败时重试原文件或任务，不自动创建新的全量导出。

底栏预留屏幕安全区和内容间距，输入软键盘出现时隐藏。桌面及手机尺寸在 Edge 中验收；物理 iPhone/Safari、真实软键盘和客户浏览器保存对话框仍需设备验收，不以模拟视口替代。

## 发布边界

仅更新明确列出的静态文件，保留现有认证、账号有效期、scope、撤销和管理权限。数据及研究来源不变，策略对比继续下线。发布流程核验源码哈希、排空当前任务、保存备份，切换后验证健康版本和已安装插件。公开仓库仅记录功能与合成验收，不包含服务端源码、真实客户资料或凭据。
