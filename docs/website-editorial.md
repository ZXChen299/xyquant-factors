# 研究网页内容与版式

本轮更新现有研究服务网页，Windows 插件仍为 `0.3.0-rc.1` 预发布版。无需更换 EXE 或新增授权；网页登录与客户端 OAuth 授权仍是各自的有效会话。

## 浏览研究

首页先提供策略与因子入口、最新已发布记录和完整策略目录；分类与计数来自本次已授权目录。策略沿用原目录顺序及既有摘要，不选“代表策略”、不根据收益排名。以前首页从目录前三项中读取年度表现的展示已撤除。

团队入口继续展示已发布成员与研究方向，没有添加未经确认的头像、成果、负责人关系或公开联系方式。数据仍在登录之后读取。

## 查看单个策略

详情按已有摘要、统计口径、净值图、策略说明、年度/月度原表及出处组织。只有原表存在唯一“策略表现”行或唯一单行时提供指标摘要，并明确原组合名称、各列标签、统计期间、来源和原表说明；其他多组合情况直接保留原表，不猜测哪个组合应当被代表。

净值日期与指标统计期间分别展示；原数据值、空值、费用、样本外说明和来源警告保留。图表名称沿用原表列标签，未单列的基准、负责人或研究结论不会补造。时间范围仅调整显示，不重算整体表现。

手机控制分为时间范围与读数/全屏两组，详情开头减少重复标题与下载按钮。已有侧栏、返回位置、账户隔离偏好、长按及安全下载行为保留，见 [交互说明](website-interactions.md)。

## 因子与接入

因子以中文名称为主要标签、原代码为次级标识，检索包含详细说明。实际数据请求与导出继续使用原标识，原值、覆盖范围与空档提示保持原样。

接入页按首次安装、已安装插件、授权到期或范围不足、旧版迁移分段。保留当前发布版本、安装命令和连接管理。账号数据权限与 OAuth scope 分别检查；旧授权不会自动扩权。策略对比继续下线，旧链接返回下线说明。

## 交付与边界

网页使用既有发布流程：静态文件明确列入清单、保护既有修改、同镜像回归、队列复查、备份和可回滚切换。公开仓库只含客户端与产品说明，不含私有服务端源码、研究资料或凭据。

浏览器验收使用合成研究资料，生产查询采用已有授权和有界样本，不创建真实导出或更改客户状态。Edge 桌面和手机视口不能代替物理 iPhone/Safari 验收。CI 验证公共客户端；私有网页和服务端由独立验收记录提供证据。
