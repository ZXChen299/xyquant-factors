# 研究资料 MCP：预发布版 0.2.0-rc.1

本版需使用配套研究 MCP 服务端。已固定安装 0.1.0-rc.1 的客户需选择新版市场来源并更新插件。研究资料保留在私有服务端，客户端仓库只包含代码、工具描述及合成测试样本。

## 能力

| 工具 | 返回内容 |
|---|---|
| `list_strategies` | 按关键词、分类分页搜索已发布策略；保留原目录顺序 |
| `get_strategy_info` | 说明、报告标题、费用、样本外说明、净值范围及受保护网页入口 |
| `get_strategy_performance` | 原表整体、年度和月度表现，保留指标名称、区间、空值及来源 |
| `get_strategy_nav` | 原表净值按日期和 offset 分页，每页最多 50 行 |
| `get_research_team` | 已发布团队介绍及原表联系方式，支持搜索和分页 |

这些工具不执行新回测、排名或指标重算。所有结果带发布版本、工作簿来源摘要和警告。净值查询必须携带目录返回的 `version`；版本变化返回 `version_changed`，客户端应从新版本重新开始。完整 CSV 和原始 Excel 沿用受保护网页下载，研究 ID 不适用于因子导出下载工具。

## 授权

OAuth 研究访问需独立的 `research:read`。授权页面明确显示策略、净值和团队联系方式范围。旧令牌及刷新令牌不会自动增加权限，现有因子功能不因此失效。

本版在新的网页登录请求中申请该范围；已有连接仍会被登录工具复用。客户明确同意重新授权后，可断开当前连接，再登录并在网页确认。这会影响同一 Windows 用户共享的连接。不得自动删除凭据或把权限不足当作令牌过期。

后端沿用服务令牌、短时签名客户上下文及逐请求令牌／客户状态校验。普通网页 API 继续拒绝 OAuth；新工具只经 `/mcp` → `/internal/v1/tools/<tool>` 读取 `ResearchStore` 的已发布版本。API Key 仍按原有有效客户研究访问规则处理。没有逐策略授权、草稿读取、上传或发布工具。

## 线上状态与验证

2026-10-03 已通过真实客户本人确认的 OAuth 完成五个研究工具的线上读取、净值小样本翻页及已安装 EXE 调用，之后也验证了默认连接。数据版本、来源及原表口径均保留。详见[本版验收记录](acceptance-0.2.0-rc.1.md)；这些结果不代表其他客户已经完成授权。

客户端：Python 3.12 环境运行 `python -B -m unittest discover -s client -p "test_*.py"`。构建使用既有 `scripts/build.py`；完成后运行 `scripts/check_release.py` 检查公开包边界及源码／EXE 摘要一致性。

服务端新增 `test_research_mcp.py`，复用项目原有依赖与合成工作簿夹具，覆盖 OAuth scope、旧授权刷新、客户停用／过期、签名上下文、版本翻页、原表口径、空值及损坏文件。

本版验收结果和未测项目见[本版验收记录](acceptance-0.2.0-rc.1.md)。配套服务端使用独立发布流程同步更新后端和 MCP 网关，并以事务迁移统一有效新旧账号数据权限；保留备份、迁移审计和按原策略回滚。OAuth scope、令牌与后台角色不参与迁移。没有线上新建客户或代客户同意研究授权。
