# 0.2.0-rc.1 实际验收记录

最近补充：2026-10-03。Windows x64 预发布版，程序未签名。以下明确区分本地测试、真实线上验收和未覆盖场景；公开文档不记录账号身份、授权链接、令牌或研究数据值。

## 2026-10-03 真实线上与已安装插件验收

在客户明确同意后，由客户本人在 Windows 浏览器登录并确认因子查询、导出、下载和研究读取授权。独立连接以 Windows DPAPI 加密保存，范围与最长 30 天有效期经过核对，原连接未自动扩权。

本轮协议、插件与文件检查合计 **38 PASS、0 FAIL、0 BLOCKED、2 NOT_RUN**：

| 范围 | 实际结果 |
|---|---|
| 网络与证书 | 正常证书／IP 身份校验通过；TLS 1.3；网站和研究入口 HTTP 200 |
| OAuth discovery | HTTP 200；四项 scope 及 PKCE S256 均已公布 |
| 认证边界 | 匿名／无效令牌 MCP 请求 HTTP 401；匿名文件下载 HTTP 401；OAuth 访问普通网页研究 API 和管理 API HTTP 403 |
| MCP 协议 | initialize HTTP 200，协商 `2025-11-25`；初始化通知 HTTP 202；无状态模式不签发会话 ID |
| 工具发现 | 远端 11 个数据工具；已安装 EXE 的 STDIO 入口提供 17 个工具 |
| 五个研究工具 | 目录、详情、原表表现、净值、团队查询均成功；响应保留发布版本、来源及原表口径 |
| 净值翻页 | 小样本连续两页、每页两行，固定同一版本，日期无重叠，分页结果未被标记为完整序列 |
| 因子查询 | 实际目录、详情和单因子／单日期／单股票预览成功 |
| 导出与本地下载 | 同样有界条件的 Parquet 文件实际下载成功；大小、SHA-256、行数及日期／代码／数值与同条件预览一致 |
| 部署身份 | 通过既有管理通道只读核验后端与网关运行同一发布版本，区别于 MCP 协议返回的服务信息 |

两项 NOT_RUN：没有改变真实账号制造停用／到期／撤销场景；所取净值样本不含空值，因此本轮未覆盖真实空值保留样本。相关合成测试属于下述单独证据。

随后，经客户另行确认，将已验证授权切换为默认连接，旧凭据保留加密备份。使用安装包原始默认配置、没有测试专用状态目录覆盖，**6 项检查通过**：17 工具发现、同一运行进程读取切换后的连接、策略查询、团队查询、因子搜索和单行预览。scope 与连接期限未改变，不需要重启该插件进程即可读取新凭据。

本次未复现业务代码缺陷，未因验收而发布新的程序或重部署服务。上述默认连接切换仅影响获准的本机用户，不会随 GitHub 发布同步给其他客户。

同日同步文档前追加默认插件复核：首轮策略表现查询返回一次 `network_error`，此前目录与详情成功但耗时约 12–13 秒；没有将该轮记为全通过。重新执行后，五个研究工具、因子查询及安装产物／授权保持检查共 **11 项通过、0 失败**，数据工具耗时约 1.5–2.7 秒。两容器仍运行、重启次数为 0，网页正常。网络错误未再次复现，根因尚未确定；所查 15 分钟容器日志没有可用条目，不能据此排除所有服务端异常。未修改网络、超时或生产配置来消除该错误。

## 仍然存在的限制

- 本次只验收已获准的单个真实客户环境，没有重新完成全新 Windows／干净物理机、两真实客户、多进程故障重启及跨宿主退出验收；不得称为这些场景全部通过。
- `host_bound` 环境中的登录、下载仍需当前 Codex 宿主运行。此前限制见 [早期验收记录](acceptance.md)。
- 未重新导入或发布真实工作簿；六项依赖原工作簿的服务端测试仍按上述记录跳过。工作簿和真实研究结果不进入公开仓库。
- 每页净值最多 50 行，不执行新回测或指标重算；完整净值 CSV 和 Excel 继续经受保护研究网页下载。
- 当前仓库没有启用 GitHub Actions，提交不存在自动 CI 通过结论。文档中的测试结果来自实际本地和线上执行。

## 发布与客户更新

固定安装标签为 `v0.2.0-rc.1`。2026-10-03 仅补充 `main` 分支文档和验收说明，程序、原标签及发布资产保持不变；固定包中的文档仍是发布时快照。
