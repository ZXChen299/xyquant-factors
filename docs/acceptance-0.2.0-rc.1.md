# 0.2.0-rc.1 实际验收记录

记录日期：2026-10-01。此版本是 Windows x64 预发布版，程序未签名。

## 已执行

- 客户端 Python 3.12：57 项测试通过，0 失败，覆盖原有登录、下载、客户任务隔离，以及五个研究工具的参数和错误处理。
- 构建后的 EXE 通过真实 STDIO 初始化，发现 17 个工具；未登录研究调用被拒绝。使用独立临时状态目录，未替换已安装插件。
- 客户端 SDK → MCP 网关 → 后端：五个研究读取工具及三类拒绝场景通过，使用本机合成数据和隔离凭据。
- 服务端在生产同一镜像与资源限制中运行 95 项测试：89 通过，6 项原始工作簿测试跳过，0 失败。覆盖已发布数据、版本翻页、统计口径、空值、OAuth scope、停用／到期／撤销、网页 OAuth 边界、导出和下载。
- 默认数据权限迁移覆盖事务、重复执行、回滚、后来管理员修改的冲突保护；不修改令牌、scope、API Key 或账号角色。新自助注册、后台创建及旧申请审批均默认全部因子、完整日期范围，有效期保留各入口原规则。
- 部署流程安全检查 4 项通过，检查容器限制保留、异常配置拒绝、WAL 备份路径及异常容器归属保护。
- 配套服务端已同步更新后端与 MCP 网关；真实账号迁移前后逐项比较确认 OAuth 凭据、角色、启用状态、有效期和研究发布记录未改变。迁移重复运行未产生额外修改。

首次隔离容器测试使用 256 MiB 临时盘，14 项导出测试触发原有 3 GiB 空闲空间保护。改用私有磁盘测试目录后全部相关测试通过；生产磁盘保护没有降低。
