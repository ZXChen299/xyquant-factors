# A+ 研究网站更新

此更新复用现有研究数据、网页登录和 MCP 服务，客户端版本保持 `0.3.0-rc.1`。

策略对比已下线：网页入口和专属 API 停止提供服务，远端 MCP 不再发现 `compare_strategies`。既有 `0.3.0-rc.1` 本地插件仍列出 20 个工具，其中对比入口只返回已下线说明，不返回对比数据；远端现在发现 13 个数据工具。无需重新登录。本次没有更新客户端 EXE、标签或发布资产。私有服务端源码和研究资料不随公开客户端仓库分发；本页不包含客户身份、真实研究数值或凭据。

## 页面与数据

- 首页保留原目录顺序和筛选，增加侧边导航、快捷入口、来源与最近发布卡片；手机布局纵向排列，导航可横向滚动。
- 年度图按目录顺序最多检查前三个策略，展示找到的第一份原始年度表；最多最近六行、前三个百分比列。图中数字、列名、日期及部分年度标记来自原表，完整原表可展开；未找到或读取失败时明确说明。
- 年度图只表示一个策略，不混合不同策略区间。缺失值保持为空，零值单独标记，不补零、插值、年化或重算；保留期间、来源、费用及资料警告。
- 研究方向图显示当前目录的分类数量，不是资产配置权重或绩效排名；不随下方本地目录筛选改变。
- 最近发布只请求一条已发布记录，资料发布时间与净值截止日分别显示；完整历史在更新页查看。
- 策略详情的净值曲线更换配色和线型，保留空值间断、图例和缩放；原始 Excel、净值 CSV 与因子下载流程不变。

## 权限与发布边界

账号启用状态、有效期、OAuth scope、撤销、管理员边界及全部 API 保持现有规则。网页更新不替用户登录、不改变令牌 scope，也不触发客户端升级。

初始 A+ 上线覆盖明确列出的 13 个静态文件；后续仅修复统计卡片间距为 12px。本次另下线对比前端和服务端调用，不删除资料。发布流程克隆现有运行版本、检查旧资源及源码树摘要，用相同镜像执行隔离回归；切换前检查任务队列，备份数据库、研究目录及原容器配置，保留旧容器供回滚。发布标识单独记录，软件版本不伪装成新的稳定版。

## 验证范围

本地浏览器使用合成资料验证页面、图表原值、空值、部分年度、版本冲突、取消重试及移动布局；这与真实账号生产验收分别记录。对应提交的 Windows Actions 只验证公开客户端源码、构建和发布边界，不包含私有服务端源码。

正式切换后须核对部署标识、静态文件摘要、正常 TLS、公开页面及既有 OAuth 会话的只读 MCP 查询。没有可用网页登录会话时，真实登录后的页面人工验收仍标为未运行；不会为截图创建权限或绕过登录。全新 Windows、物理手机、多客户完整回归和真实故障回滚演练不属于此次网页改版验收。
