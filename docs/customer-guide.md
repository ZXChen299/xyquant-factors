# 客户使用说明

本文描述 `v0.2.0-rc.2` 测试版的使用流程，市场来源为 [GitHub 仓库](https://github.com/ZXChen299/xyquant-factors)。测试版有尚未完成的客户场景，请先查看[本版验收记录](acceptance-0.2.0-rc.2.md)。

**登录和下载完成前请保持当前 Codex 对话运行。** 当前验证版本限制后台任务独立于 Codex 运行；结束对话或完全退出可能中断任务，下一次查询会显示中断并允许重试。Codex 会在当前回合等待并查询进度，不应先结束回合让你稍后继续。一次运行就退出的 `codex exec` 不能用来跨退出等待任务。

## 安装与首次登录

在 Windows 10/11 x64 上安装并登录 Codex。在插件市场添加维护者提供的 XYQuant GitHub 来源，选择 **XYQuant 因子** 并安装。插件已经包含所需运行程序，不需要另装 Python 或连接助手。

先在 GitHub Releases 确认 `v0.2.0-rc.2` 已发布；如果使用 Codex CLI，执行：

```powershell
codex plugin marketplace add https://github.com/ZXChen299/xyquant-factors.git --ref v0.2.0-rc.2
codex plugin add xyquant-factors@xyquant
```

打开研究项目，在对话中说“连接我的 XYQuant 因子账号”，或者直接提出因子查询需求。未登录时，Codex 会返回授权入口。请在运行插件的同一台 Windows 电脑上打开授权页，输入手机号与密码，并亲自确认允许连接；密码只输入网站，不发到对话里。授权回调返回该电脑的本地监听端口，因此在手机上打开此链接不能替电脑完成回调。

没有账号时，先在另一个浏览器标签页打开[现有注册页](https://47.103.215.251/factors/apply)。按注册页填写必要信息并设置密码。注册后初始权限按网站显示生效，管理员可后续调整。注册完成后返回原授权页面继续登录；注册链接本身不会为插件完成授权。

授权完成后返回 Codex，原对话会继续查询和处理。登录入口五分钟内有效，过期后在对话中说“重新登录 XYQuant”。若授权已经完成并保存后对话才结束，可以回复“已登录，继续”；如果授权未完成时会话结束导致中断，则需要重新发起登录。以后授权有效时可以直接取数。连接最长 30 天，并受账号有效期限制；短期 access token 到期后可自动刷新，刷新不会增加 scope 或延长连接期限。

## 从旧版本升级

如果市场来源固定在 `v0.1.0-rc.1`，先将该来源选择为 `v0.2.0-rc.2`，再按 Codex 提示更新或重新安装插件。刷新旧固定标签不会自动升级到另一个标签。看到新增工具通常需要重新打开会话；仅切换已明确获准的默认连接时，下一次调用会读取当前凭据，已验证同一 `0.2.0-rc.1` 进程无需重启。

账号可访问研究资料不代表旧插件连接已获 `research:read`。出现 `research_authorization_required` 时，由客户明确选择断开并重新登录，再在网页确认研究范围；`start_login` 会复用已有连接，反复调用不能自动扩权。不要把权限不足误当成网站故障。

## 在对话中查询

可以直接使用以下指令：

> 列出我能访问的波动率相关因子。

> 查看 vol_entropy 的说明和可查询日期范围。

> 查询 vol_entropy 在 2026-09-11 的 000001.SZ 因子值。

预览最多返回 50 行。Codex 应标明因子、起止日期和股票条件。空值保持为空，无数据会明确提示。预览用于核对数值，不能代表完整结果的统计分布。

## 查询策略与团队

可以要求“搜索已发布的策略，查看说明、原表表现和净值”或“介绍研究团队”。工具返回版本、来源和统计期间；每页净值最多 50 行，不执行新回测。完整净值 CSV 和原始 Excel 从[受保护研究网页](https://47.103.215.251/factors/research)下载。

有效新旧账号默认具有全部已发布数据访问权限，不需管理员逐项开通。已有因子 OAuth 连接不会自动增加 `research:read`。出现研究授权不足时，明确要求断开并重新登录，再在网页同意策略、净值和团队介绍（含联系方式）权限；此操作影响同一 Windows 用户共享的连接。原有因子查询不受此新增范围影响。

## 下载完整数据

在当前研究项目中说：

> 下载 vol_entropy 在 2026-09-11 的 000001.SZ 数据，保存到当前项目。

Codex 先创建服务器导出任务，再由插件后台下载。若当前项目目录不明确，会先让你确认。文件固定存放在：

```text
<研究项目>/downloads/factors/<任务编号>/
```

只有本地下载完成并通过大小、SHA-256 校验，才算成功。服务器已完成导出并不代表文件已保存到你的电脑。多个下载会排队执行；同一任务重复要求保存到同一项目会复用本地任务。已有内容不同的文件不会被覆盖，ZIP 不会自动解压。

文件保留一小时，从服务器导出完成时计时。已过期的导出不能再下载，需要你明确提出重新导出。网络中断会有限重试；如果仍失败，可以在对话中查询下载状态并重试。后台程序不作为 Windows 常驻系统服务运行。工具提示 `host_bound` 时，任务依赖当前 Codex 宿主存活；完全退出后重新打开 Codex，检查中断结果，并在云端文件尚未过期时重新发起本地下载。

## 连接管理与常见问题

| 情况 | 做法 |
|---|---|
| 想查看登录状态 | 说“查看 XYQuant 连接状态” |
| 授权过期或被撤销 | 说“重新登录 XYQuant”，完成新的浏览器授权 |
| 研究授权不足 | 明确同意替换当前连接，再断开、登录并在网页同意 `research:read` |
| 本地显示已连接但请求失败 | 本地状态未获服务器实时确认，以实际请求错误为准 |
| 因子或日期不在权限内 | 联系管理员调整权限；重复登录不会扩大权限 |
| 下载还在等待 | 让 Codex 查看本地下载进度，不要重复创建同一云端导出 |
| 文件过期 | 明确要求重新导出；插件不会擅自重建任务 |
| 退出 Codex 后任务中断 | 保持新会话打开，重新登录或重试本地下载；无须另开助手 |
| 想换一个账号 | 先说“断开当前 XYQuant 连接”，再发起登录 |
| 安装后看不到工具 | 按 Codex 提示重新打开会话，检查插件是否已启用 |

“断开连接”会清除当前 Windows 用户共享的插件授权，其他 Codex 窗口也需重新登录。它不删除已下载文件，也不取消服务器上已经创建的导出任务。

网页退出登录只结束网页会话。要撤销客户端连接，可在对话中断开，或在[连接管理页面](https://47.103.215.251/factors/connect)撤销。插件禁用或卸载不会删除研究项目中的文件，也不等同于服务器撤销授权。

如果你此前安装过连接助手或手动配置过同一 MCP，请参阅[迁移说明](migration.md)，避免两个入口同时出现。


## 网络恢复说明

`0.2.0-rc.2` 新增有限的只读重试。创建导出仍只提交一次；结果不明时先用 `get_export(request_id=原编号)` 核对。未找到不证明原请求未执行，保留原编号和条件，勿改编号重复创建。

“停止等待”仅停止当前本地等待，不等于取消后台导出或上传。上传、发布及撤销结果不明时先读取状态再决定；认证或权限拒绝需要处理连接状态，不能靠反复提交解决。需要排障时提供请求编号和安全错误码即可，不提供密码、令牌或研究数据。未发布的候选不作为客户安装来源。
