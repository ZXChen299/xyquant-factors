# 客户使用说明

本文描述 `v0.1.0-rc.1` 测试版的使用流程，市场来源为 [GitHub 仓库](https://github.com/ZXChen299/xyquant-factors)。测试版有尚未完成的客户场景，请先查看[实际验收记录](acceptance.md)。

**登录和下载完成前请保持当前 Codex 对话运行。** 当前验证版本限制后台任务独立于 Codex 运行；结束对话或完全退出可能中断任务，下一次查询会显示中断并允许重试。Codex 会在当前回合等待并查询进度，不应先结束回合让你稍后继续。一次运行就退出的 `codex exec` 不能用来跨退出等待任务。

## 安装与首次登录

在 Windows 10/11 x64 上安装并登录 Codex。在插件市场添加维护者提供的 XYQuant GitHub 来源，选择 **XYQuant 因子** 并安装。插件已经包含所需运行程序，不需要另装 Python 或连接助手。

如果使用 Codex CLI，执行：

```powershell
codex plugin marketplace add https://github.com/ZXChen299/xyquant-factors.git --ref v0.1.0-rc.1
codex plugin add xyquant-factors@xyquant
```

打开研究项目，在对话中说“连接我的 XYQuant 因子账号”，或者直接提出因子查询需求。未登录时，Codex 会返回授权入口。点击后在因子网站输入手机号与密码，并确认允许连接；密码只输入网站，不发到对话里。

没有账号时，先在另一个浏览器标签页打开[现有注册页](https://47.103.215.251/factors/apply)。当前注册流程填写姓名、手机号、机构名称；默认密码为 `Xyzq888888`，勾选“自己设置密码”可设置个人密码。注册后自动开通，初始权限按网站显示生效，管理员可后续调整。注册完成后返回原授权页面继续登录；授权页面内新增的注册入口尚未部署，本教程直接提供可用的注册链接。

授权完成后返回 Codex，原对话会继续查询和处理。登录入口五分钟内有效，过期后在对话中说“重新登录 XYQuant”。若授权已经完成并保存后对话才结束，可以回复“已登录，继续”；如果授权未完成时会话结束导致中断，则需要重新发起登录。以后授权有效时可以直接取数。

## 在对话中查询

可以直接使用以下指令：

> 列出我能访问的波动率相关因子。

> 查看 vol_entropy 的说明和可查询日期范围。

> 查询 vol_entropy 在 2026-09-11 的 000001.SZ 因子值。

预览最多返回 50 行。Codex 应标明因子、起止日期和股票条件。空值保持为空，无数据会明确提示。预览用于核对数值，不能代表完整结果的统计分布。

## 下载完整数据

在当前研究项目中说：

> 下载 vol_entropy 在 2026-09-11 的 000001.SZ 数据，保存到当前项目。

Codex 先创建服务器导出任务，再由插件后台下载。若当前项目目录不明确，会先让你确认。文件固定存放在：

```text
<研究项目>/downloads/factors/<任务编号>/
```

只有本地下载完成并通过大小、SHA-256 校验，才算成功。服务器已完成导出并不代表文件已保存到你的电脑。多个下载会排队执行；同一任务重复要求保存到同一项目会复用本地任务。已有内容不同的文件不会被覆盖，ZIP 不会自动解压。

文件保留一小时，从服务器导出完成时计时。已过期的导出不能再下载，需要你明确提出重新导出。网络中断会有限重试；如果仍失败，可以在对话中查询下载状态并重试。后台程序不作为 Windows 常驻系统服务运行。工具提示 `host_bound` 时，任务依赖当前 Codex 宿主存活；完全退出后重新打开 Codex，检查中断结果，并在云端文件尚未过期时重新发起本地下载。

## 连接管理与常见问题

| 情况 | 做法 |
|---|---|
| 想查看登录状态 | 说“查看 XYQuant 连接状态” |
| 授权过期或被撤销 | 说“重新登录 XYQuant”，完成新的浏览器授权 |
| 因子或日期不在权限内 | 联系管理员调整权限；重复登录不会扩大权限 |
| 下载还在等待 | 让 Codex 查看本地下载进度，不要重复创建同一云端导出 |
| 文件过期 | 明确要求重新导出；插件不会擅自重建任务 |
| 退出 Codex 后任务中断 | 保持新会话打开，重新登录或重试本地下载；无须另开助手 |
| 想换一个账号 | 先说“断开当前 XYQuant 连接”，再发起登录 |
| 安装后看不到工具 | 按 Codex 提示重新打开会话，检查插件是否已启用 |

“断开连接”会清除当前 Windows 用户共享的插件授权，其他 Codex 窗口也需重新登录。它不删除已下载文件，也不取消服务器上已经创建的导出任务。

网页退出登录只结束网页会话。要撤销客户端连接，可在对话中断开，或在[连接管理页面](https://47.103.215.251/factors/connect)撤销。插件禁用或卸载不会删除研究项目中的文件，也不等同于服务器撤销授权。

如果你此前安装过连接助手或手动配置过同一 MCP，请参阅[迁移说明](migration.md)，避免两个入口同时出现。
