# 管理员说明

插件复用现有[管理后台](https://47.103.215.251/factors/admin)。插件安装和更新不创建另一套客户数据库，用户的因子范围、日期权限、有效期及任务归属始终以后台为准。

## 向客户交付

正式发布后，交付 GitHub 插件市场来源和[注册页](https://47.103.215.251/factors/apply)即可。普通客户无需 API Key，无需单独安装连接助手。

当前网站采用自助注册：填写姓名、手机号、机构名称，并使用默认或自设密码，立即开通。注册初始权限为永久有效、全部因子可用，包含之后新增因子；管理员可按业务需要调整客户范围。客户端源码公开不等于数据开放，所有请求仍须登录并通过权限检查。

客户登录自己的因子账号，通过网站确认 OAuth 授权。不要代收客户密码，也不需要把管理账号或服务器密钥交给客户。

本版将有效新旧普通客户统一为全部已发布数据访问：全部因子和完整日期范围、策略、净值与团队介绍。自助注册、后台创建及旧申请审批的新账号沿用该数据默认值；有效期仍按各入口的既有规则确定。账号停用、到期、后台角色及 OAuth 撤销规则不变。旧 OAuth scope 不自动增加，研究工具需客户重新同意 `research:read`。

## 日常管理

- 在客户记录中调整启用状态、授权有效期、因子清单及日期范围。权限收紧按已有规则影响目录、预览、待执行任务及历史文件下载。
- 在“已授权连接”中查看客户端、创建时间、最近使用和到期时间；支持撤销单个连接或客户全部连接。
- 查看客户的网页与 MCP 导出任务、下载记录及失败原因。区分权限问题、源数据问题、队列繁忙和本地下载失败。
- 重置密码完成后，网页会话和 OAuth 连接撤销；独立 API Key 仍按原有规则管理。

停用或到期的客户不能继续使用插件取数。重新启用后需要重新授权。仅撤销一个客户端连接不会取消该客户已经提交的云端导出任务。

## 发布和支持

将经过验收的版本发布到 GitHub，再更新市场来源指向的版本。随发布提供程序校验值、更新说明、支持的 Codex 版本和实际验收记录。不要把未执行的干净环境、自然语言对话或兼容测试标成通过。

支持排障时收集插件版本、Codex 版本、任务编号、错误代码、保存目录和错误发生时间即可。不收集密码、访问令牌、刷新令牌、完整 OAuth 回调 URL 或客户导出文件内容。

首次客户交付前验证“安装插件 → 对话登录 → 查询数值 → 下载文件”完整流程。系统签名状态应随版本注明；不承诺所有 Windows 安全软件均无提示。

旧连接助手客户可按[迁移说明](migration.md)切换，现有独立 API Key 无需统一作废。公共服务回滚仍须保留客户隔离和当前数据库兼容性。
