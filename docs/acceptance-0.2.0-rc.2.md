## 凭据和生命周期

单次云端请求预算包含等待认证；超时不会中断或重发正在进行的令牌刷新。同一连接目录复用在途认证结果。下载任务先保存可查询的失败状态，后台退出前等待已有认证操作保存完成；退出收尾不属于工具响应时间。401 后本地凭据清理占锁时跳过，但服务端拒绝立即生效，旧 token 不会删除新凭据。强制关闭宿主仍可能中断操作，届时需重新登录。

共享默认密码、账号默认权限、OAuth scope 和显式授权行为保留。旧连接不自动扩权；旧助手迁移仍只处理已确认属于本服务的配置，并保留凭据和本地下载记录。
