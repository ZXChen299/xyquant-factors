# 从连接助手或独立 MCP 迁移

新客户直接安装插件，不需要本步骤。本文适用于已经安装旧连接助手，或在 Codex 中配置了 `xyquant_factors` 的 Windows 用户。

## 迁移步骤

1. 安装 XYQuant 因子插件，并确认插件已启用。
2. 在对话中说：

   > 将我的旧 xyquant_factors 独立配置迁移到 XYQuant 因子插件，保留其他 MCP 和现有登录状态。

3. Codex 调用插件内置程序的 `--migrate-legacy` 命令。命令只在确认旧配置属于本服务后，备份配置并移除对应独立入口。若同名配置属于其他服务，会停止并说明冲突。
4. 重新打开 Codex 会话，查询连接状态并做一次小数据查询。已有有效授权可直接复用，无需再交付 Key。

迁移命令由插件内置程序执行，路径以当前插件实际安装目录为准：

```text
<插件安装目录>/bin/FactorBridge.exe --migrate-legacy
```

维护者从仓库测试时，对应路径是 `plugins/xyquant-factors/bin/FactorBridge.exe`。不要把维护者机器上的路径写进客户配置。

## 迁移保留哪些内容

插件继续使用 `%LOCALAPPDATA%/XYQuant/FactorConnect` 中受 Windows DPAPI 保护的凭据和本地任务记录，不创建第二套刷新凭据。迁移不会修改其他 MCP 服务，不撤销现有 API Key，不删除下载文件。

配置备份保存在原配置旁。迁移返回的备份路径可用于人工恢复，但恢复后避免同时启用旧入口和插件，以免对话重复发现同一服务。

**不要运行旧连接助手的卸载清理。** 旧卸载可能删除插件共享的凭据和下载记录。迁移只移除旧的 Codex 独立配置入口；无需为了使用插件而清理旧安装文件。

插件禁用或卸载不会自动撤销服务器连接。需要结束授权时，先在对话中“断开 XYQuant 连接”，或在网页连接管理中撤销；研究项目内的已下载文件保留。
